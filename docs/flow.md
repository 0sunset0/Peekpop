# Flow — Peekpop

8개 화면, 선형 흐름. 각 결정의 배경은 ade.md 참고.

0. **온보딩** (최초 1회, 스킵 불가) — 3페이지 캐러셀, 서로 다른 예시 사진 + 동일 문구("폰 카메라 앱을 켜고, 화면에 인물이 보이게 찍어주세요"). 마지막 페이지 "시작하기" → 1
1. **메인** — "사진 선택하기" 버튼만 (미니멀, 로고/문구 없음) → 2
2. **사진 선택** — iOS 표준 시트(카메라/앨범). 앨범 선택은 권한 불필요. 선택 즉시 확인 없이 → 3
3. **화면 경계 확인** — 대상은 "폰 화면 전체"가 아니라 **카메라 UI(상태바·버튼) 제외, 사진이 보이는 부분만**. Vision 자동 검출로 4꼭짓점 프리필(실패 시 인물 사진 비율의 기본 사각형), 사용자가 드래그로 확정. 뒤로가기 가능(→2). "확인" → 4
4. **오브젝트 마스크 생성 (로딩)** — 3의 영역으로 크롭 후 AI 마스크 초안 생성. 그럴싸하면 → 6, 애매하면 → 5 (판정 임계값은 code-architecture.md/구현 단계에서 튜닝)
5. **브러시 보정 (조건부)** — AI 마스크 오버레이, 브러시 추가/제거(굵기 조절), 전체 초기화. 빈 마스크로 "완료"해도 진행 막지 않음. "완료" → 6
6. **합성 (로딩)** — 컷아웃 확대·재배치(사각형 기울기 반영)·그림자 → 최종 이미지(원본 비율 유지)
7. **결과** — 저장/공유하기/다시 만들기. 수정 버튼 없음. 저장 탭 시 버튼이 체크마크로 잠깐 바뀌어 피드백. "다시 만들기" → 2 (메인이 아님)

## 환경/예외

- 다크 테마 고정(시스템 설정 안 따름), 세로 화면 고정.
- 카메라 권한 거부(2번, 촬영 선택 시) → 설정 이동 안내.
- 사진 저장 권한 거부(7번, "저장" 탭 시) → 설정 이동 안내. (앨범에서 고르는 건 권한 자체가 없음)
- Vision 실제 오류(인식 실패가 아닌 예외) → "다시 시도" 단일 버튼 화면 → 2번으로.
- 접근성(VoiceOver, Dynamic Type 등) MVP 미지원, iOS 기본값만.

## 공통 컴포넌트
Primary 버튼(CTA 전 화면 공용), 로딩 인디케이터(4·6 공용), 안내 문구 스타일(0·3·5 공용), 페이지 인디케이터(0).
