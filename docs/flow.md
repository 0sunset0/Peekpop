# Flow — Peekpop (v0)

5개 화면, 선형 흐름. tech-critic-lead 게이트(2026-08-29)로 온보딩 캐러셀과 브러시 보정 UI를 다음 버전으로 미뤘다 — 근거는 `docs/prd.md`의 "v0 스코프 결정", 각 화면 결정의 기술적 배경은 `docs/ade.md` 참고.

1. **메인** — "사진 선택하기" 버튼 + 예시 사진 1장 + 안내 문구("폰 카메라 앱을 켜고, 화면에 인물이 보이게 찍어주세요"). 온보딩 캐러셀 없음, 이 한 화면이 안내를 겸한다 → 2
2. **사진 선택** — iOS 표준 시트(카메라/앨범). 앨범 선택은 권한 불필요. 선택 즉시 확인 없이 → 3
3. **화면 경계 확인** — 대상은 "폰 화면 전체"가 아니라 **카메라 UI(상태바·버튼) 제외, 사진이 보이는 부분만**. Vision 자동 검출로 4꼭짓점 프리필(실패 시 인물 사진 비율의 기본 사각형), 사용자가 드래그로 확정. 뒤로가기 가능(→2). "확인" → 4
4. **처리 (로딩)** — 3의 영역으로 크롭 → AI로 인물 마스크 생성 → 결과가 degenerate(커버리지가 임계치 밖 — 거의 비어있거나 거의 전체)하면 브러시 보정 없이 곧장 에러 화면("다시 시도해주세요" 단일 버튼 → 2)으로. degenerate가 아니면 컷아웃 확대·재배치(사각형 기울기 반영)·그림자 합성까지 이어서 진행 → 5
5. **결과** — 자동 배치된 결과를 보여주고, **저장 전에 드래그(이동)/핀치(크기)/두 손가락 회전으로 배치를 직접 조정**할 수 있다(조정할 때마다 즉시 재합성해 미리보기에 반영 — Vision을 다시 부르지 않아 빠름). 조정 UI는 브러시로 마스크 자체를 고치는 것과는 다르다(그건 여전히 v0 범위 밖) — 이미 오려낸 피사체를 어디에 얼마나 크게 놓을지만 조정한다. 버튼 위계: **저장**이 이 화면의 메인 액션이라 꽉 찬 primary 버튼(라벨 "저장"+아이콘), 공유하기는 그 바로 옆에 붙는 작은 원형 아이콘 버튼(같은 줄). 다시 만들기는 되돌리는 행동이라 그 아래에 배경 없는 텍스트 링크로 따로 뺀다 — 셋을 똑같은 크기로 나란히 두지 않는다(디자인 리뷰 반영). 저장 탭 시 화면 하단에 "저장되었어요" 토스트가 잠깐 떴다 사라짐. "다시 만들기" → 2 (메인이 아님)

## 환경/예외

- 다크 테마 고정(시스템 설정 안 따름), 세로 화면 고정.
- 카메라 권한 거부(2번, 촬영 선택 시) → 설정 이동 안내.
- 사진 저장 권한 거부(5번, "저장" 탭 시) → 설정 이동 안내. (앨범에서 고르는 건 권한 자체가 없음)
- Vision 실제 오류(인식 실패가 아닌 예외) 또는 마스크 degenerate → "다시 시도" 단일 버튼 화면 → 2번으로. 두 경우 모두 같은 에러 화면 재사용.
- 접근성(VoiceOver, Dynamic Type 등) v0 미지원, iOS 기본값만.

## 공통 컴포넌트
Primary 버튼(CTA 전 화면 공용), 로딩 인디케이터(4 전용), 안내 문구 스타일(1·3 공용).
