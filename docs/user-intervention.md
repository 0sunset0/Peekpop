# User Intervention Required

CLI/AI 에이전트가 자체적으로 완결할 수 없어서, 사람이 직접 수행해야 하는 항목들.

## 1. 소셜 검증 (선택, 권장)

`docs/vibecoding/01-구현가능성검증.md`의 스파이크에서 실제로 만든 합성 샘플(정면 샷/기울어진 샷)을 개인 인스타그램·샤오홍슈 계정 또는 관련 커뮤니티에 올려서 반응(저장, 댓글, "어떻게 만들었어?" 질문)을 관찰하는 것을 권장한다.

- **왜 사람이 해야 하는가**: 실제 소셜 계정 게시·타인의 유기적 반응 관찰은 본인 계정으로만 가능하고, 인위적으로 만들어낼 수 없다.
- **완료 후 할 일**: 반응이 있었다면 무엇을(저장 수, 댓글 내용 등) 관찰했는지 기록해두면 다음 스코프 확장(스티커, 결과 보정 등) 논의 때 근거로 쓸 수 있다.
- **필수 아님**: MVP 출시 자체를 막지 않는다 — [현재 시장 조사](#2-참고-시장-조사-완료)로 트렌드 자체의 실재성은 이미 CLI로 확인됨.

## 2. (참고) 시장 조사 — 완료

CLI 웹 검색으로 확인: "폰 화면 밖으로 튀어나오기" 효과는 실제로 TikTok/Reels에서 현재 유행 중인 트렌드다. 경쟁은 이미 존재한다 — Gen.ai의 "Screen Pop-Out 3D AI Photo Generator", "POP3", "AI Mirror" 같은 전용 앱/웹툴이 있고, 가장 흔한 제작 방법은 ChatGPT/Gemini 같은 생성형 AI에 사진을 올리고 프롬프트 한 줄로 만드는 것이다(Picsart 자체 블로그도 이 방법을 안내). Picsart의 배경 제거+수동 레이어링(~15분) 튜토리얼은 여러 대안 중 하나일 뿐이다.

**Peekpop의 차별점**: 생성형 AI 방식은 계정·API 비용·네트워크가 필요하고 인물을 "재해석"하는 과정에서 원본과 달라질 위험(할루시네이션)이 있다. Peekpop은 무계정·완전 무료·온디바이스·세그멘테이션 기반이라 인물을 실사 그대로 보존한다(`docs/ade.md`에서 검증됨). 경쟁이 있다는 사실 자체가 수요의 증거이고, Peekpop은 그 경쟁 대비 명확한 포지셔닝을 가진다. (사람이 개입할 필요 없었음, 참고용으로만 기록)

## 3. App Store 제출

계정 서명, 스크린샷 준비, 심사 제출은 Apple Developer 계정을 가진 사람이 직접 해야 한다. 구현이 끝나면 이 항목을 갱신한다.

- **개인정보처리방침 — 작성 완료(2026-08-30)**: https://claude.ai/code/artifact/bce88861-ae3d-41c2-ae93-6b98b010201c 에 호스팅. App Store Connect 제출 시 이 URL을 그대로 쓰면 된다. 문의 이메일은 초안 상태(`printf.sunset@gmail.com`)라 필요하면 바꿔서 다시 게시할 것.
- 나머지(Apple Developer 계정 가입, 앱 아이콘, 스크린샷, App Privacy 설문, 연령 등급, 가격 설정, 서명)는 여전히 사람이 직접 해야 함.
