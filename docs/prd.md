# PRD — Peekpop

## 제품
아이폰 화면에 인물 사진이 떠 있는 사진을 입력하면, 그 인물이 화면 밖으로 튀어나온 것처럼 보이는 합성 사진을 만들어주는 iOS 앱. ("폰 화면 뚫고 나오기" 트렌드 편집의 자동화)

## 타겟 & 배포
- 개인 서비스, 무계정(로그인 없음), iOS 단일 플랫폼, App Store 배포
- MVP는 완전 무료. 다음 버전에서 "하루 1회 무료, 이후 유료" 과금 도입 예정 — 계정이 없으므로 기기 로컬 상태로 처리 (data-schema.md에 필드 예약됨)

## 제품 철학
- 검증하려는 가설은 "이 트렌드 사진 기능 자체가 매력적인가"이지 "AI 품질이 완벽한가"가 아니다. 완성도 있는 단일 경험에 집중하고, 스티커·보정 등 부가 기능은 YAGNI로 다음 버전에 미룬다.
- "속도 vs 안정성": 자동 인식은 있어도 결과를 조용히 신뢰하지 않는다 — 실패든 애매함이든 사용자가 매끄럽게 수동으로 이어받아 항상 정상적인 결과가 나가게 한다 (근거: ade.md).

## v0 스코프 결정 (tech-critic-lead 게이트, 2026-08-29)
증거 없이 화면 수가 많은 풀 프로덕션 버전으로 바로 가는 안은 거부됐다. 시장 조사(경쟁 존재 확인 — Gen.ai, ChatGPT 프롬프트 방식 등. `docs/user-intervention.md` 참고)로 수요 증거를 보강하고, 온보딩 캐러셀과 브러시 보정 UI를 다음 버전으로 미루는 조건으로 승인받았다. 단, "이상한 결과가 조용히 나가지 않는다"는 성공 기준을 지키기 위해 세그멘테이션 결과가 명백히 degenerate할 때 재시도로 유도하는 최소 게이트는 유지한다.

**추가 결정(실기기 QA 이후, 사용자 오버라이드)**: 자동 배치 결과의 위치·크기 조정 UI("결과 수동 보정")도 처음엔 tech-critic-lead가 "알고리즘 튜닝(더 싼 대안)을 먼저 시도하라"며 거부했다. 배치를 크롭 중심 기준 동적 계산으로 고친 뒤에도 실기기 사용자가 재요청해, 사용자가 이 판단을 오버라이드하고 v0 범위에 다시 포함시켰다(FR4 참고). 근거는 `docs/ade.md`.

**추가 결정(디자인 리뷰, 2026-08-30)**: 메인 화면의 예시 사진 1장을, 사용 흐름(①어떤 사진을 찍는지 ②노란 점을 어디에 맞추는지 ③결과가 어떻게 나오는지)을 보여주는 3페이지 스와이프 캐러셀 + 페이지 인디케이터로 확장했다. 이건 위에서 미룬 "온보딩 캐러셀"(메인 진입 전 별도 화면 시퀀스, 스킵/완료 절차 있음)과는 다르다 — 화면 수는 그대로고, 기존 "예시 사진 1장" 슬롯이 3장으로 늘어난 것뿐이라 v0 스코프 결정과 상충하지 않는다. 상세는 `docs/flow.md`.

## 핵심 플로우 (요약 — 상세는 flow.md)
사진 선택 → 화면 영역 지정(자동 프리필 + 수동 확인) → 인물 추출(AI, degenerate 시 재시도 유도) → 합성(자동 배치 + 저장 전 드래그/핀치 조정) → 저장/공유

## 기능 요구사항
- FR1. 카메라 촬영 또는 앨범에서 사진 1장을 입력받는다.
- FR2. 화면에 보이는 인물 사진 영역을 사용자가 확정한다 (자동 검출은 초안일 뿐, 최종 신뢰하지 않음).
- FR3. 그 영역 안의 인물을 배경에서 분리한다 (AI로 자동 추출). 결과가 명백히 degenerate(거의 비어있거나 거의 전체를 덮음)하면 합성하지 않고 재시도 화면으로 보낸다 — 브러시로 직접 마스크를 보정하는 UI는 v0에 없음.
- FR4. 분리된 인물을 화면 경계 밖으로 확대·재배치하고 그림자로 입체감을 준다. 배치는 사용자가 지정한 사각형의 기울기를 반영하고, 크롭 영역 중심을 기준으로 확대해 원본 피사체 위치를 그대로 덮는다. 결과 화면에서 저장하기 전에 드래그(이동)·핀치(크기)로 배치를 직접 조정할 수 있다.
- FR5. 결과를 카메라롤에 저장하고 공유할 수 있다.

## 비기능 요구사항
- 완전 온디바이스 처리 — 네트워크 없이 100% 동작.
- 계정/로그인/서버 없음.
- 최소 iOS 17.

## MVP(v0) 범위 밖 (다음 버전)
- 온보딩 캐러셀 (메인 진입 전 별도 화면 시퀀스 — v0는 메인 화면 안의 3페이지 예시 캐러셀 + 안내 문구로 대체, 위 "추가 결정" 참고)
- 브러시로 마스크를 직접 보정하는 UI (v0는 degenerate 시 재시도로만 유도 — 위치/크기 조정과는 별개, 이건 여전히 범위 밖)
- 장식 스티커 자동 배치
- 과금 로직 (하루 1회 무료 등)
- 서버 기반 고정밀 세그멘테이션

## 성공 기준
- 사진 선택부터 결과까지 전체 플로우가 실기기에서 끊김 없이 동작한다.
- 자동 인식이 실패하거나 명백히 degenerate해도, 사용자가 재시도로 매끄럽게 이어갈 수 있어 이상한 결과가 조용히 나가는 일이 없다.
