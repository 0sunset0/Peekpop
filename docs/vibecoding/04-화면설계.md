# 4. 화면 설계 — Peekpop

작성일: 2026-08-29
상태: 완료

[[03-사용자흐름점검]]에서 확정한 화면 흐름을 화면별로 구체화한다. 각 화면의 목적, 핵심 UI 요소, 레이아웃, 상태, 다음 화면 연결을 정리한다.

|---|---|---|

## 화면별 상세

### 0. 온보딩

- **목적**: 최초 실행 시 "어떤 사진을 찍어야 하는지" 학습시킨다.
- **핵심 UI 요소**: 예시 사진(전체 폭에 가깝게 크게), 안내 문구(3페이지 모두 동일 — "폰 카메라 앱을 켜고, 화면에 인물이 보이게 찍어주세요"), 페이지 인디케이터(점 3개), 마지막 페이지에만 "시작하기" 버튼.
- **레이아웃**: 상단~중앙에 큰 예시 이미지, 하단에 안내 문구 → 페이지 인디케이터 → (3페이지만) 시작하기 버튼.
- **상태**: 1/2/3페이지, 스와이프로만 이동, 스킵 버튼 없음(반드시 3페이지 다 봐야 함).
- **예시 사진 소스**: 실제 후보로 검토했던 원본 사진 3장(정면 거치대, 촬영 중, 기내)을 그대로 재사용.
- **다음 화면**: 3페이지에서 "시작하기" → 1. 메인.

### 1. 메인

- **목적**: 앱 진입점, 새 결과물 만들기 시작.
- **핵심 UI 요소**: "사진 선택하기" 버튼 하나.
- **레이아웃**: 화면 중앙에 버튼만, 로고/문구 없이 미니멀.
- **상태**: 단일 상태.
- **다음 화면**: 버튼 탭 → 2. 사진 선택.

### 2. 사진 선택

- iOS 표준 카메라/포토 라이브러리 선택 시트(PHPicker + 카메라). 별도 커스텀 디자인 없음.
- **다음 화면**: 사진 선택/촬영 완료 → 3. 화면 경계 확인.

### 3. 화면 경계 확인

- **목적**: 폰 화면 사각형 영역을 확정한다.
- **핵심 UI 요소**:
  - 선택한 사진이 전체 화면 배경
  - 4꼭짓점을 드래그할 수 있는 사각형 오버레이 — Vision 자동 검출 성공 시 그 결과로 프리필, 실패 시 폰 화면 비율(세로로 긴 형태)의 기본 사각형이 사진 중앙에 배치
  - 안내 문구 (예: "폰 화면 네 모서리에 맞춰주세요")
  - 뒤로가기 버튼 (다른 사진 다시 고르기)
  - "확인" 버튼
- **레이아웃**: 전체화면 이미지+오버레이, 상단에 뒤로가기, 하단에 안내 문구와 확인 버튼.
- **상태**: 자동 프리필됨 / 자동 미검출로 기본값 표시됨 — 사용자 입장에서는 시각적으로 동일하게 "조정 가능한 사각형"으로만 보임.
- **다음 화면**: "확인" → 4. 로딩 / 뒤로가기 → 2. 사진 선택.

### 4. 오브젝트 마스크 생성 (로딩)

- **목적**: 확정된 영역을 크롭하고 AI가 마스크 초안을 만드는 동안 대기시킨다.
- **핵심 UI 요소**: 스피너 + "만드는 중..." 문구.
- **분기**: 마스크가 그럴싸함 → 6. 합성 로딩으로 직행 / 애매함 → 5. 브러시 보정.

### 5. 브러시 보정 (조건부)

- **목적**: AI가 그린 마스크 초안을 사용자가 다듬는다.
- **핵심 UI 요소**:
  - 크롭된 화면 이미지가 배경
  - AI 마스크 초안이 반투명 색으로 오버레이
  - 브러시 — 기본은 "추가" 모드, 지우개 아이콘을 눌러 "제거" 모드로 전환
  - 브러시 굵기 슬라이더
  - 전체 초기화 버튼
  - 안내 문구 (예: "튀어나오게 하고 싶은 부분을 칠해주세요")
  - "완료" 버튼
- **레이아웃**: 전체화면 이미지+마스크 오버레이, 상단에 안내 문구, 하단에 브러시 굵기 슬라이더 + 지우개/초기화 아이콘 + 완료 버튼.
- **다음 화면**: "완료" → 6. 합성 로딩.

### 6. 합성 (로딩)

- **목적**: 컷아웃 + 확대·재배치 + 그림자 렌더링으로 최종 이미지를 만드는 동안 대기시킨다.
- **핵심 UI 요소**: 스피너 + "만드는 중..." 문구 (4번과 동일한 컴포넌트).
- **다음 화면**: 완료 → 7. 결과.

### 7. 결과

- **목적**: 완성된 이미지를 확인하고 저장/공유한다.
- **핵심 UI 요소**: 완성 이미지(원본 사진 비율 유지), "저장" 버튼, "공유하기" 버튼, "다시 만들기" 버튼. 수정 버튼 없음.
- **상태/인터랙션**: "저장" 탭 시 버튼이 잠깐 체크마크로 바뀌었다가 원래 상태로 돌아옴(저장 완료 피드백).
- **다음 화면**: "다시 만들기" → 2. 사진 선택으로 복귀 (메인이 아니라 바로 사진 선택으로, [[03-사용자흐름점검]]과 동일).

## 공통 컴포넌트

| 컴포넌트 | 사용 화면 | 비고 |
|---|---|---|
| Primary 버튼 | 시작하기(0) / 확인(3) / 완료(5) / 저장·공유·다시 만들기(7) | 하나의 공용 CTA 버튼 스타일 |
| 로딩 인디케이터 (스피너 + 문구) | 4, 6 | 동일 컴포넌트 재사용 |
| 안내 문구 텍스트 | 0, 3, 5 | 동일한 텍스트 스타일/위치 규칙 |
| 뒤로가기 버튼 | 3 | 표준 iOS 뒤로가기 패턴 |
| 페이지 인디케이터(점) | 0 | 표준 iOS 페이지 컨트롤 |
