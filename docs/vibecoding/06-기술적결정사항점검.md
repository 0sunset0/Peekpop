# 8. 기술적 결정사항 점검 — Peekpop

작성일: 2026-08-29
상태: 완료

1~5번 문서(구현 가능성 검증 / 기술 스택 선정 / 사용자 흐름 점검 / 화면 설계 / 데이터·코드 아키텍처 설계)를 다시 훑으며 모순, 빠진 결정, 최종 문서 생성 전에 막힐 만한 지점을 점검했다.

## 점검 중 고치고 넘어간 것

- **[[01-구현가능성검증]] 결론 문장 수정**: "화면 경계는 자동 검출에 의존하지 않고..."로 남아있던 초기 결론이, 이후 실제 채택한 방식("자동 검출은 초안으로만 쓰고 사용자가 항상 확인/조정")과 미묘하게 어긋나 있었다. 문서 내 제약 조건·[[03-사용자흐름점검]]과 일치하도록 결론 문장을 수정했다.
- **[[04-화면설계]] 권한 처리 항목 분리**: "카메라/사진 접근 권한 거부"를 하나로 뭉뚱그려 놨었는데, 실제로는 둘이 다르다.
  - 앨범에서 사진을 **고르는** 건 `PHPickerViewController` 방식이라 애초에 권한 프롬프트가 없다 (iOS가 앱과 격리된 프로세스에서 선택만 넘겨줌).
  - 권한이 실제로 필요한 순간은 (1) 카메라로 **촬영**할 때, (2) 결과를 카메라롤에 **저장**할 때, 이 두 곳뿐이고 시점도 다르다(2번 화면 vs 7번 화면). 문서를 이 두 시점으로 나눠 정정했다.

## 새로 확인된, 반드시 필요한 기술적 결정

지금까지 문서 어디에도 없었지만 앱이 아예 동작하려면 필요한 것들이다.

### Info.plist 권한 안내 문구

iOS는 권한을 요청할 때 앱이 지정한 문구를 시스템 다이얼로그에 보여준다. 이게 없으면 해당 기능 요청 시 앱이 크래시한다. 두 개만 필요하다 (사진 선택은 권한이 없으므로 문구 불필요):

| 키 | 문구(안) | 트리거 시점 |
|---|---|---|
| `NSCameraUsageDescription` | "폰 화면에 보이는 사진을 촬영하기 위해 카메라 접근이 필요해요" | 2번 화면에서 카메라 선택 시 |
| `NSPhotoLibraryAddUsageDescription` | "완성된 사진을 앨범에 저장하기 위해 접근이 필요해요" | 7번 화면에서 "저장" 탭 시 |

문구는 언제든 바꿔도 되는 카피성 텍스트라 지금 확정하지 않아도 되지만, 자리 자체는 구현 시작 전에 있어야 한다.

### 개인정보 매니페스트 (Privacy Manifest)

Apple은 `@AppStorage`(UserDefaults) 같은 "required reason API"를 쓰는 앱에 `PrivacyInfo.xcprivacy` 파일에 사용 근거(reason code)를 선언하도록 요구한다 — 이게 없으면 App Store 심사에서 반려된다. [[05-데이터및코드아키텍처설계]]에서 `@AppStorage`를 쓰기로 했으므로 해당된다. 구현 시 Xcode가 기본 템플릿을 제공하니 추가 논의 없이 표준 선언만 채우면 된다.

### 앱 아이콘 / 브랜딩

이 9단계 파이프라인 어디에도 앱 아이콘·브랜딩 작업이 없다 — [[04-화면설계]] 때도 짚었던 미결 사항이다. App Store 제출 전에는 반드시 필요하지만, 이 문서 체계(요구사항→구현) 밖의 별도 작업이므로 여기서는 "빠뜨리지 말아야 할 항목"으로만 남겨둔다.

## 그 외 훑어본 것 (문제 없음 확인)

- 문서 간 크로스 레퍼런스([[01-구현가능성검증]] 등)가 실제 파일과 어긋나지 않는지 확인 — 이상 없음.
- [[02-기술스택선정]]의 스택 목록이 [[05-데이터및코드아키텍처설계]]의 서비스 구성과 1:1로 맞물리는지 확인 — 이상 없음.
- [[03-사용자흐름점검]]의 8단계 흐름이 [[04-화면설계]]의 화면 8개와 정확히 대응하는지 확인 — 이상 없음.
- MVP 범위 밖으로 미룬 항목들(스티커, 결과 보정, 과금 로직, 서버 세그멘테이션)이 여러 문서에 흩어져 있지만 서로 모순되지 않음을 확인.

## 완료 기준

- [x] 1~5번 문서를 다시 읽고 상호 모순되는 문장을 찾아 고쳤다.
- [x] 앱이 실제로 빌드·실행되려면 필요한데 어느 문서에도 없던 항목(Info.plist 권한 문구, 개인정보 매니페스트)을 찾아 기록했다.
- [x] 문서 체계 밖에 있어 별도로 챙겨야 할 항목(앱 아이콘/브랜딩)을 명시했다.
